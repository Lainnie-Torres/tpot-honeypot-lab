# T-Pot Honeypot Lab – Findings & Lessons Learned

## 🔍 PROJECT FINDINGS

This project provided hands-on experience deploying and exploring **T-Pot Community Edition**, an open-source multi-honeypot platform designed to observe and collect network activity.

Through the deployment and monitoring process, I gained exposure to how honeypots can be used to observe interactions with exposed services and support security monitoring.

A more detailed analysis of collected events and observed activity will be added as the lab data is reviewed.

## 🧠 TECHNICAL SKILLS DEVELOPED

Throughout this project, I gained practical experience with:

- **Linux Administration:** Working within an Ubuntu Server environment and navigating the Linux command line.
- **Virtualization:** Configuring and managing a virtual machine using Oracle VirtualBox.
- **Docker:** Exploring containerized services used by the T-Pot platform.
- **Network Configuration:** Configuring NAT networking and port forwarding to access the T-Pot web interface.
- **Security Monitoring:** Exploring honeypot dashboards and network activity visualizations.
- **Threat Observation:** Learning how honeypots collect information about interactions with exposed services.

## ⚠️ CHALLENGES & TROUBLESHOOTING

During deployment and configuration, I worked through several environment and access-related challenges.

These included:

- Configuring VirtualBox networking and port forwarding.
- Establishing access to the T-Pot web interface.
- Navigating the Linux command-line environment.
- Verifying the installed T-Pot version.
- Exploring the platform's Docker-based architecture.

Working through these challenges reinforced the importance of troubleshooting, documentation, and understanding how different components interact within a security monitoring environment.

## 🎯 KEY TAKEAWAYS

This lab helped strengthen my understanding of:

- How honeypots support cybersecurity research and threat observation.
- How Linux and Docker are used to deploy security tools.
- How network activity can be collected and visualized.
- How virtualization can provide an isolated environment for security experimentation.
- The importance of documenting technical configurations and troubleshooting processes.

## 🚀 NEXT STEPS

Future work on this lab will include:

- Reviewing collected security events in greater detail.
- Identifying patterns in observed network activity.

- Documenting notable observations with supporting screenshots.

## 📚 PROJECT CONCLUSION

The T-Pot Honeypot Lab provided an opportunity to explore an open-source security monitoring platform in a hands-on virtual environment.

The experience strengthened my practical knowledge of Linux administration, virtualization, Docker, network configuration, and cybersecurity monitoring while providing a foundation for further exploration of threat analysis.
