## 🔍 MONITORING OVERVIEW

After deploying T-Pot, I explored its monitoring capabilities to understand how honeypots collect and visualize network activity.

T-Pot provides a centralized environment for monitoring interactions with deployed honeypot services. Its dashboards and visualization tools make it possible to explore incoming connections, identify activity patterns, and investigate potential security threats.

This section documents my exploration of the T-Pot monitoring interface, Attack Map, and collected security events.
