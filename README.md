## 🔍 LAB OVERVIEW

This project explores **T-Pot**, an open-source multi-honeypot platform designed to collect, visualize, and analyze network activity for security monitoring.

The lab was deployed using **Oracle VirtualBox** and an **Ubuntu Server** virtual machine. T-Pot uses Docker to deploy multiple honeypot services and supporting tools, creating an environment for observing network interactions and exploring potential security threats.

Through this project, I gained hands-on experience with Linux administration, Docker container management, honeypot deployment, and security monitoring.

## 🧰 TECHNOLOGIES USED

- **Oracle VirtualBox** – Virtualization
- **Ubuntu Server** – Linux operating system
- **T-Pot** – Multi-honeypot platform
- **Docker** – Container management
- **Nginx** – Web server and reverse proxy
- **Elasticsearch** – Data storage and search
- **T-Pot Attack Map** – Network activity visualization

## 🎯 LAB OBJECTIVES

1. Deploy a T-Pot honeypot environment within an Ubuntu Server virtual machine.
2. Configure virtual machine resources and network settings.
3. Explore T-Pot's Docker containers and deployed honeypot services.
4. Access and navigate the T-Pot web interface and Attack Map.
5. Examine network activity and explore collected security events.
6. Develop practical experience with Linux administration, container management, and security monitoring.
7. Document the deployment process, observations, troubleshooting steps, and lessons learned.
